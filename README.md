## PlaywrightProject
### Project Overview
This project includes Playwright-written automation scripts for testing the SauceDemo website. Login, product selection, cart addition, and checkout are some of the key features covered by the scripts.
### Language Used
JavaScript
### Technology Used
Node.js
Playwright
Allure Reporter
Git & GitHub
### To Execute The Project
Clone the repository:
```bash
git clone https://github.com/Farhana-Yeasmin4/PlaywrightProject.git
```

Run Scripts:
It will execute the cases and generate allure report
```bash
npm run testReport
```
It will execute only the first test case
```bash
npm run test1
```
It will execute only the second test case
```bash
npm run test2
```
It will execute only the third test case
```bash
npm run test3
```
